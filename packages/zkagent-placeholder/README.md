# zkagent

Placeholder package. zkagent is under development and not yet usable — this
package exists only to reserve the name.

zkagent is human-rooted, privacy-preserving authentication for AI agents: a
per-service tag derived from a passport/ID scan, used to authorize agents
acting on a person's behalf. The verifier SDK, `chiproof`, is published
separately.
