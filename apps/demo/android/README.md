# apps/demo/android — historical test rig (not part of the shipped demo)

**This is an unbuilt, unverified, historical rig.** It is an old dev-side Android test app from the
`spikes/m2-handoff` days, kept in the tree only because it came along when that spike became
`apps/demo` (D73). It is **not** the scanner (`apps/scanner` is the app), it is **not** part of the
shipped demo, and it has not been built or run on a device since its cleartext config was narrowed
(see the "Android app" section of `../README.md`). Do not lift it; `docs/product/reuse-map.md` lists
it under "Not worth lifting as-is".
