## 5 — NOT device-checked (stated, not hidden)

- **Under-threshold popup**: the demo hardcodes 18, and its test-only `?threshold=` would trip chiproof's
  `threshold_mismatch` instead of reaching this popup. It uses the same refusal switch as the others and is
  code-inspected only.
- **Redirect and no-well-known-key paths (finding #41)**: loopback uses the built-in dev key and never fetches
  `/.well-known/zkagent-verifier`. These paths are covered only by `WellKnownKeyTest`, including the real loopback
  sockets. A real-TLS device run would need a hosted https site.
- **Night colours**: not exercised (finding #45 stays open).
